📝 NoteApp — Interactive Sticky Notes Board

📌 Overview

NoteApp is an intuitive, web-based sticky notes application designed for quick ideas, reminders, and brainstorming sessions. Users can click anywhere on an interactive board workspace to pin notes with custom color choices.

"Click anywhere on the board to capture your thoughts visually."

🛠️ Tech Stack

HTML5 — Semantic markup, accessible labels (sr-only), and UI structure.

CSS3 (style.css) — Styling for the toolbar, color pickers, board layout, and sticky note animations.

JavaScript (script.js) — Dynamic DOM creation, coordinate-based note positioning, color selection handling, and bulk actions.

💡 Key Features

📍 Click-to-Add Notes: Simply click anywhere inside the board canvas to create a new sticky note at that exact position.

🎨 Color Customization: Choose from 5 preset note themes:

🟡 Yellow (#fef08a)

🔵 Cyan (#a5f3fc)

🔴 Red (#fca5a5)

🟢 Green (#bbf7d0)

🟣 Indigo (#c7d2fe)

🗑️ Clear All Board: Instantly clear all active notes from the board with a single click.

💡 Guided Onboarding: Helpful visual cue/hint on empty boards to guide new users.
